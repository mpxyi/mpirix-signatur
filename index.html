Erstelle deine Mpirix Signatur

Daten eingeben, Signatur kopieren und in Outlook einfügen.

1. Deine Angaben

Link zu deinem LinkedIn-Profil.

Deine Angaben bleiben auf dieser Seite. Sie werden weder gespeichert noch an einen Server gesendet.

2. Deine Signatur

LIVE-VORSCHAU

Fülle alle Pflichtfelder aus. LinkedIn wird nur mit gültigem Link angezeigt.

3. In Outlook einfügen

  1. Öffne im neuen Outlook oder in Outlook Web Einstellungen → Konten → Signaturen.
  2. Wähle dein Konto, erstelle eine Signatur namens Mpirix und füge sie mit Strg + V (Mac: ⌘ + V) ein. Falls gefragt: Quellformatierung beibehalten.
  3. Wähle sie für neue Nachrichten sowie Antworten und Weiterleitungen aus und speichere.
Outlook Classic oder Mac

Classic (Windows): Datei → Optionen → E-Mail → Signaturen → Neu.

Mac: Outlook → Einstellungen → Signaturen. Neue Signatur erstellen, einfügen und für das gewünschte Konto als Standard auswählen.

Das Logo fehlt nach dem Einfügen?

Falls Outlook das eingebettete Logo entfernt, füge das Original-PNG im Signatur-Editor über «Bild einfügen» links ein und stelle die Grösse auf 100 × 100 Pixel. Prüfe das Ergebnis mit einer Test-E-Mail.

Kopieren aus Notion klappt nicht?

Wähle «Manuell kopieren», danach Strg + C bzw. ⌘ + C. Alternativ öffne die eingebettete Seite über ihre Original-URL in einem eigenen Browser-Tab und kopiere dort.

Sende dir eine Test-E-Mail, um Formatierung und Links zu prüfen. Die Darstellung kann je nach Outlook-Version abweichen. Microsoft-Anleitung

2. Deine Mobile Signatur

LIVE-VORSCHAU

Für Outlook auf iOS: Diese Signatur wird als reiner Text ohne Logo und HTML-Formatierung kopiert. So ist sie unabhängig von der Bild- und Formatierungsunterstützung der App.





Dieselben Personendaten, automatisch übernommen. LinkedIn bleibt der Desktop-Signatur vorbehalten.






3. Auf dem iPhone einfügen


  1. Öffne diese Seite auf deinem iPhone, fülle deine Angaben aus und tippe auf Mobile Signatur kopieren.
  2. Öffne die Einstellungen in Outlook und suche Signatur.
  3. Ersetze die bisherige Signatur durch den kopierten Text. Falls du mehrere Konten verwendest, wähle das passende Konto.
  4. Sende dir eine Test-E-Mail und prüfe die Angaben.


Falls automatisches Kopieren nicht verfügbar ist: Tippe auf «Manuell kopieren» oder halte den Vorschautext gedrückt und wähle ihn zum Kopieren aus.
